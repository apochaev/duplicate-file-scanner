## Fixtures and fakes

- HTTP: `provideHttpClient()`, `provideHttpClientTesting()`; each request answered with `HttpTestingController` (`expectScan`, `expectFolders`, `expectSets`, `expectSummaries`, `expectPairs`, `expectPair` from `result-test-data.ts`); `http.verify()` after each test.
- Stub surfacing: `provideStubSurfacing()` in the providers and `await settle(fixture)` after each step.
- Fakes behind tokens: `DENSITY_STORAGE` (a Map-backed `getItem`/`setItem`, cleared in `beforeEach`, pre-filled for the restore test); `CLIPBOARD` (`FakeClipboard` in `path-copy.spec.ts`, an immediately resolving recorder in `result-screen.spec.ts`, null in `sets-tab.spec.ts`).
- Data builders: `scanEntry`, `folder`, `duplicateSet`, `setPage` from `result-test-data.ts` (unchanged; it already carries `duplicateBytes`, `totalFiles`, `totalBytes`).

## Notes for the implementer

- Selectors: `.result-figures .figure-label|.figure-value`, `.space-bar .space-segment.segment-*` (inline `style.width` in %), `.space-legend li`, `.density-toggle` (toggles "Compact", "Comfortable"), `.sets-filter` (toggles "All sets", "Copies under <name>", checked state follows `filtered`), `tbody.duplicate-set`, `tr.set-header .set-name|.set-count|.set-size|.bar-fill|.set-reclaimable-bytes`, `tr.copy-row(.in-selected-folder) .short-path[title] .path-folders .path-name`, `.links-badge[title]` (paths joined by `\n`), `.selected-badge`, `.copy-modified time` (`yyyy-MM-dd`), `button.folder-select .folder-name|.folder-size|.folder-duplicate-size|.folder-bar-fill`, `button.copy-path-button` (aria-label `Copy path of <path>`).
- Overlaps loads only when its tab is selected (`matTabContent`); the screen spec expects no `/summaries` or `/pairs` request on open.
- `displayPath` examples are exact (see the doc comment): at budget 36 the long name reads `Downloads\Screen Reco…41.07 long.mov`; at budget 62 (`PATH_BUDGET`) `Backups\…\Iceland 2019\Raw Exports\Day 3\pano-final.tif`. Two edge cases rest on design note 2: a nameless root with several roots reads `C:\a\b.jpg`, a path under no root is shown absolute.
- The ticket's AC-7 scenarios use budget 36 for `displayPath` (tested directly); in the screen, `PATH_BUDGET` is 62, so the copy-button test uses a longer path.
- The page-size step of AC-8's scenario ("choose page size 50") is tested with 25 and 100, since 50 is already the default and selecting it again emits nothing.
- AC-9's "open again" is covered by a pre-filled storage test plus a stored-value check, not by creating the screen twice (the router would treat the second navigation to the same URL as a no-op).
- `app.routes.spec.ts` (DFS-049.AC-1, unchanged, outside `touches`) breaks against the stubs, as design.md predicts, and passes once `readDensity` and `browserStorage` are real.
- No spec wraps a stub call in `expect(() => ...).not.toThrow()`: that would turn the stub's `not implemented: DFS-060` into an AssertionError and fail the red gate. The AC-9 "write that throws" test calls `writeDensity` directly and asserts on the fake storage afterwards.
