# Research — 2026-11-01

Primary sources consulted before drafting the protocol. These support design choices, not savings claims for this project.

- Anthropic, effective harnesses: durable progress, feature state, and Git history aid resumption. https://www.anthropic.com/research/effective-harnesses-for-long-running-agents
- Anthropic, harness design: a richer game-maker harness improved functionality at $200 versus $9 solo; later simplification removed sprint scaffolding and reduced review frequency. Remove one component at a time. https://www.anthropic.com/research/harness-design-long-running-apps
- Cursor, scaling agents: shared-file peer coordination encountered contention and unclear ownership; separate roles helped, while an extra integrator became a bottleneck. Large experiments do not demonstrate small-project efficiency. https://cursor.com/blog/scaling-agents
- Google Research: across 180 configurations, benefits depended on task structure; sequential tasks could degrade with multi-agent coordination. https://research.google/blog/towards-a-science-of-scaling-agent-systems-when-and-why-agent-systems-work/
- Anthropic reference implementation: durable handoffs, separate evaluation, file steering, and explicit stop conditions; sample hooks require adaptation. https://github.com/anthropics/cwc-long-running-agents
- Claude hooks: lifecycle hooks can supply context. FileChanged output alone is not a reasoning turn; asyncRewake has distinct semantics. Check installed-version support. https://code.claude.com/docs/en/hooks
- Claude channels: push into running sessions, with research-preview constraints. Deferred here. https://code.claude.com/docs/en/channels

Our inference: separate writers, stable IDs/revisions, compact discovery, evidence tied to repository state, and explicit authority. Atomic publication, restart recovery, and duplicate suppression are engineering recommendations, not a validated benchmark of this exact pairing.

Local audit: 16 completed plans contained recorded phase-attempt totals of 4,733 seconds design, 4,914 tests, 3,078 implementation, and 2,255 verification. These are historical recorded times, not total delivery latency or billing data; some entries are incomplete or reconciliation records.

The implementer instructions require a full build and the green gate then runs cleanTest build --continue. Removing duplicate full validation is a candidate for a later approved experiment, preserving freshness safeguards and independent review. No savings percentage is established.
